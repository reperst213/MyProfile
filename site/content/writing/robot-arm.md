**진행 상태: 완료** · 2026년 10월 컴퓨터 그래픽스 수업 과제

## 과제의 목적

하나의 큐브를 재사용하고 크기와 위치를 변환해 로봇팔의 여러 부분을 표현했습니다. 어깨나 팔꿈치의 움직임이 연결된 하위 부분에 반영되는 구조를 이해하고, 키보드 입력으로 로봇팔을 움직이는 것이 목표였습니다.

## 작업 내용

JavaScript와 WebGL을 사용한 예제 코드를 바탕으로 하완과 손을 만들었습니다. 팔꿈치와 손목의 위치·회전을 계산하고, 상위 부분의 변환을 하위 부분에 이어 주었습니다. 키 입력으로 각 관절의 상태를 바꾸고, 바뀐 상태를 반영해 화면을 다시 그리도록 구현했습니다.

## 결과

키보드로 팔꿈치와 손목을 움직일 수 있는 로봇팔을 완성했습니다. 추가 기능으로 `G` 키를 누를 때마다 팔의 길이와 두께가 1%씩 커지도록 했고, 최대 크기는 처음의 두 배로 제한했습니다. 초기화하면 각도와 크기가 처음 상태로 돌아갑니다.

## 배운 점

상위 부분의 변환을 하위 부분에 전달하면 팔꿈치와 손목이 움직여도 각 부분의 위치 관계가 유지된다는 것을 배웠습니다. 크기 조절 기능을 만들 때도 각 부분을 따로 다시 배치하기보다, 기존 구조의 관계를 활용해 길이와 두께 값만 바꾸면 된다는 것을 이해했습니다.

또한 키 입력으로 상태를 바꾸고, 화면 버퍼를 비운 뒤 바뀐 상태로 다시 그리는 과정을 이해했습니다.
